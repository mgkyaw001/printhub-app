# PrintHub – USB All-in-One Printer (Android Native)

This is a complete Android Studio project for USB OTG printing with:
- Android USB Host API
- Full Color RGB & Monochrome Floyd-Steinberg dithering
- Android Print Framework
- PDF & Document rendering
- Myanmar Unicode support

## How to Build APK
1. Open this directory in Android Studio (Hedgehog or Iguana+).
2. Allow Gradle sync to complete.
3. Connect your Android phone via USB debugging.
4. Click 'Run' (Shift + F10) or Build -> Build APK(s).
5. The debug APK will be created at: app/build/outputs/apk/debug/app-debug.apk
